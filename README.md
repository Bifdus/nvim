# Installation

## Dependencies
Neovim (Required) - `https://github.com/neovim/neovim/blob/master/INSTALL.md`
RG (Optional) - `https://github.com/BurntSushi/ripgrep?tab=readme-ov-file#installation`
FZF (Optional) - `https://github.com/junegunn/fzf?tab=readme-ov-file#installation`
Yazi (Required for '\' file navigation) - `cargo install --locked yazi-fm yazi-cli`
LazyGit (Required for gg mapping) - `https://github.com/jesseduffield/lazygit?tab=readme-ov-file#installation`
